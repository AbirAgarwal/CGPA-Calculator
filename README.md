# Smart CGPA & SGPA Calculator

A desktop app to calculate SGPA and CGPA semester by semester, built with Python and Tkinter.

## Features
- Add subjects with credits and grades (O, A+, A, B+, B, C, F)
- Calculate SGPA per semester
- Calculate overall CGPA across all semesters
- Semester history table
- Data saved automatically to JSON (persists between runs)
- Dark mode toggle
- Input validation for credits and grades

## How to Run
```bash
python cgpa.py
```

## Requirements
- Python 3.x
- Tkinter (usually included with Python)

## Built With
- Python + Tkinter
